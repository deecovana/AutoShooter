# Godot 4 AutoLoad saved settings

To turn this settings manager into an AutoLoad (Singleton), you need to register it in your Godot project settings. 
This makes the script globally accessible from any other script in your game without needing to use get_node() or preload().

Here is the step-by-step setup in English:

## Step 1: Prepare the Manager Script

Make sure your script is saved as settings_manager.gd in your project folder. 
The code handles everything automatically when the game starts:

```gdscript
	# settings_manager.gd
	extends Node

	const SAVE_PATH = "user://game_settings.tres"
	var current_settings: GameSettings

	func _ready() -> void:
		load_settings()

	func save_settings() -> void:
		var error = ResourceSaver.save(current_settings, SAVE_PATH)
		if error != OK:
			print("Failed to save settings. Error code: ", error)

	func load_settings() -> void:
		if ResourceLoader.exists(SAVE_PATH):
			current_settings = ResourceLoader.load(SAVE_PATH) as GameSettings
			print("Settings loaded successfully!")
		else:
			current_settings = GameSettings.new()
			print("No save file found. Created default settings.")
```

## Step 2: Register it as an AutoLoad in Godot 4

	1. In the top menu of the Godot Editor, click on Project -> Project Settings.
	2. Click on the Autoload tab at the top of the settings window.
	3. Next to the Path field, click the Folder icon and select your settings_manager.gd file.
	4. In the Name field, Godot will automatically suggest a name. Change it to SettingsManager (using PascalCase is standard for singletons).
	5. Click the Add button.
	6. Make sure the checkbox in the Enable column is checked.
	7. Close the Project Settings window.

Now, Godot will instantly instantiate this script when the game launches, right before your main scene loads.

## Step 3: Access it from Any Script

Because it is a Singleton, you can call SettingsManager from anywhere in your codebase.

### Example: Saving values from an Options Menu UI

```gdscript
	# options_menu.gd
	extends Control

	func _on_volume_slider_changed(value: float) -> void:
		# Access the global AutoLoad directly
		SettingsManager.current_settings.master_volume = value
		SettingsManager.save_settings()
```
		
### Example: Reading values when the Player spawns

```gdscript
	# player.gd
	extends CharacterBody2D

	func _ready() -> void:
		# Pull the saved player name from the last session automatically
		var saved_name = SettingsManager.current_settings.player_name
		print("Welcome back, ", saved_name)
```
