# Godot 4 apply your saved settings

To apply your saved settings (like fullscreen or volume) automatically on startup, you need 
to execute the actual Godot engine commands immediately after loading the resource file.

You can handle this by adding an apply_settings() function inside your SettingsManager AutoLoad script.

## Updated settings_manager.gd Code

Replace your current AutoLoad script with this code. 
It contains the updated loading logic and the code to change window modes and audio volumes:

	# settings_manager.gd
	extends Node

	const SAVE_PATH = "user://game_settings.tres"
	var current_settings: GameSettings

	func _ready() -> void:
		load_settings()
		apply_settings() # Apply settings to the engine immediately on startup

	func save_settings() -> void:
		var error = ResourceSaver.save(current_settings, SAVE_PATH)
		if error != OK:
			print("Failed to save settings. Error code: ", error)

	func load_settings() -> void:
		if ResourceLoader.exists(SAVE_PATH):
			current_settings = ResourceLoader.load(SAVE_PATH) as GameSettings
			print("Settings loaded successfully!")
		else:
			current_settings = GameSettings.new()
			print("No save file found. Created default settings.")

	# This function passes the saved values into the Godot Engine APIs
	func apply_settings() -> void:
		# 1. APPLY VIDEO SETTINGS (Fullscreen / Windowed)
		if current_settings.fullscreen:
			DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_FULLSCREEN)
		else:
			DisplayServer.window_set_mode(DisplayServer.WINDOW_MODE_WINDOWED)
		
		# 2. APPLY AUDIO SETTINGS (Volume sliders)
		# Finds the index of the "Master" audio bus
		var master_bus_idx = AudioServer.get_bus_index("Master")
		
		# Linear-to-db conversion prevents audio popping and scales volume naturally
		var volume_db = linear_to_db(current_settings.master_volume / 100.0)
		AudioServer.set_bus_volume_db(master_bus_idx, volume_db)
		
		print("Settings successfully applied to the engine!")
		
## Best Practice for Your Options Menu

When a player changes a setting inside your options menu UI, you should update the variable, 
save the resource, and apply the change instantly so the player can see or hear the effect.

Here is how you can link your UI sliders or checkboxes using the updated AutoLoad:

	# options_menu.gd
	extends Control

	func _on_fullscreen_toggled(button_pressed: bool) -> void:
		# 1. Update the value in the resource
		SettingsManager.current_settings.fullscreen = button_pressed
		# 2. Save it to disk
		SettingsManager.save_settings()
		# 3. Apply it to the screen right away
		SettingsManager.apply_settings()

	func _on_volume_slider_changed(value: float) -> void:
		SettingsManager.current_settings.master_volume = value
		SettingsManager.save_settings()
		SettingsManager.apply_settings() # Changes the volume in real-time
